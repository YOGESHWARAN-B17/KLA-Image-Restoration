# KLA Image Restoration

**KLA Image Restoration using deep learning for degraded image enhancement**

This project develops a deep-learning image restoration model for enhancing degraded/noisy semiconductor images. The model learns to transform degraded input images into cleaner restored images while preserving important image structures.

## Project Overview

The KLA Image Restoration project contains:

- A PyTorch restoration model
- A training script for reproducing model training
- A standalone evaluation/inference script
- A trained model checkpoint
- Test-set restored outputs
- Reproducible Python dependencies

The model is designed to handle degraded grayscale images represented as NumPy (`.npy`) files.

## Dataset

The training dataset uses paired degraded and ground-truth images.

Expected training structure:

```text
data/train/
├── degraded/
│   ├── 000001_degraded.npy
│   ├── 000002_degraded.npy
│   └── ...
│
└── ground_truth/
    ├── 000001_gt.npy
    ├── 000002_gt.npy
    └── ...
```

The degraded image is the model input and the corresponding ground-truth image is the target output.

The test set contains degraded images:

```text
data/test/degraded/
├── 000001_degraded.npy
├── 000002_degraded.npy
├── ...
```

Test data may be out-of-distribution relative to the training data, so the model is evaluated on its ability to generalize to unseen images.

## Test Inference and Evaluation

The standalone `evaluate.py` script is designed to run inference directly from the command line without manually editing paths.

Run:

```bash
python evaluate.py --input_dir data/test/degraded --output_dir outputs/test_restored
```

The script automatically loads:

```text
checkpoints/best_model.pt
```

It then:

1. Finds all `*_degraded.npy` test images.
2. Loads the trained model.
3. Runs inference on every test image.
4. Saves each restored image as a PNG.
5. Reports the number of images processed.
6. Reports total inference time.
7. Reports average inference time per image.
8. Reports throughput in images per second.

Restored outputs are saved to:

```text
outputs/test_restored/
```

Example:

```text
000001_degraded.npy
        ↓
KLAImageRestorationNet
        ↓
000001_restored.png
```

## Quantitative Evaluation

Evaluation on the paired evaluation dataset produced the following average results:

| Metric | Degraded | Restored |
|---|---:|---:|
| PSNR | 24.69 dB | **28.35 dB** |
| SSIM | 0.5982 | **0.7622** |

Improvement:

- PSNR: **+3.66 dB**
- SSIM: **+0.1640**

These values show that the restored images have improved similarity to the ground-truth images compared with the degraded baseline.

## Inference Speed

The standalone evaluation script measures inference time for every input image.

Run:

```bash
python evaluate.py --input_dir data/test/degraded --output_dir outputs/test_restored
```

At the end of execution, the script reports:

```text
Images processed: ...
Total inference time: ... seconds
Average inference time: ... ms/image
Throughput: ... images/second
```

The reported speed depends on the hardware used for execution. GPU inference is expected to be faster than CPU inference.

## Notes

- Input images are grayscale NumPy arrays.
- Input values are normalized/clipped to the expected `[0, 1]` range by the inference pipeline.
- The trained model checkpoint must remain at `checkpoints/best_model.pt` unless a different checkpoint is supplied with `--checkpoint`.
- Test outputs should be generated using the submitted model weights and evaluation script.
- Large datasets that are supplied separately by KLA do not need to be duplicated in the repository unless required by the submission instructions.
